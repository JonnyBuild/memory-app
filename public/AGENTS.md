# Public Assets

> Assets servis tels quels par Vite/GitHub Pages.

## Key files

- `manifest.webmanifest` — configuration PWA.
- `pwa-icon.svg` — icone installable et favicon.

## Local rules

- Les chemins publics doivent rester compatibles avec `/memory-app/`.
- Si le repo GitHub change de nom, mettre a jour `manifest.webmanifest`, `index.html` et `vite.config.ts`.
- Ne pas ajouter de gros assets publics sans verifier le poids du build.
